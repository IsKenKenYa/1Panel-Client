# 报告解读指南（report-guide）

modtree 生成两份产物：交互式 HTML 依赖图（供人浏览）与 Markdown 分析报告（供 Agent 与人阅读结构化结论）。汇报结论时优先引用 MD 报告与 stdout 统计。

## stdout 关键标记

| 标记 | 含义 |
|------|------|
| `[+] 解析完成: 共 N 个文件级节点` | 日志解析成功 |
| `[+] 分析完成: 模块数 N \| 依赖边数 N \| 业务域数 N \| 循环依赖 N 组`（单行） | 聚合分析成功 |
| `[OK] 完成！耗时 X 秒` + `HTML:` / `Markdown:` 路径 | 全流程成功（退出码 0） |
| `[ERROR] ...` | 致命失败，退出码 1 |
| `[WARN] ...` | 非致命告警（如 Markdown 生成失败不影响退出码） |
| `[!] 警告: 自动拉取日志超时` + `[r]/[m]/[q]` 菜单 | 真机采集进入人工交互逃逸分支 |

## HTML 交互图（dependency_graph.html）

纯静态单文件，双击即用，无需联网。布局分三栏：

| 区域 | 内容 |
|------|------|
| 左侧面板 | 统计卡片（文件 / 模块 / 边数 / 循环组）、被依赖数与依赖数 Top 15 排行榜、循环依赖列表 |
| 中间画布 | DAG 拓扑依赖图：双击节点切换根节点、滚轮缩放、拖拽平移、自适应缩放按钮 |
| 右侧面板 | 选中节点的完整文件路径与所属模块；"依赖项 / 调用者"表格，支持模糊过滤与点击跳转 |

**核心视觉约定：实线边 = 静态导入（`[static]`），虚线边 = 动态依赖（`[dynamic]`）。**
动态依赖行在右侧面板带绿色边框，悬浮显示 specifier（触发动态加载的原始导入说明符）；静态行悬浮显示 `static 依赖`。

## Markdown 报告（同名 .md）章节速查

| 章节 | 内容 | 回答什么问题 |
|------|------|--------------|
| `## 概览` | 文件级节点数、聚合后模块数、依赖边数、业务域数、循环依赖组数 | 整体规模 |
| `## 域分布` | 各业务域的模块数与占比 | 模块都分布在哪些域 |
| `## 域级依赖总览` | Mermaid 图：域间聚合依赖（仅模块数 ≥3 的域、权重 ≥5 的边） | 哪些域耦合紧密 |
| `## 核心模块依赖图` | Mermaid 图：扇入/扇出 Top 20 模块，按域分组（权重 ≥2 的边） | 核心模块的依赖结构 |
| `## 扇入排行 (被依赖最多的模块)` | 排行表 | 哪些模块被依赖最多（基础库热点） |
| `## 扇出排行 (依赖最多的模块)` | 排行表 | 哪些模块依赖最多（复杂度高） |
| `## 循环依赖 (警告)` | 每个环的模块链路 `A -> B -> (回到起点)` 与涉及模块清单 | 哪些模块互相引用（无此章节 = 0 组） |
| `## 模块依赖邻接表` | 按域分组列出每个模块的文件数、扇入/扇出、依赖与被依赖清单（含次数） | 某模块依赖了谁 / 被谁依赖 |
| `## 依赖边权重排行 (Top 50)` | 源模块 → 目标模块及权重 | 哪两个模块耦合最紧密 |

**依赖边权重** = 两个模块之间的文件级依赖数量，权重越高表示耦合越紧密。

## 汇报建议

- 先给概览数字（模块数 / 边数 / 循环组数），再按用户关注点引用对应章节（排行、循环、邻接表）。
- 存在循环依赖时必须主动提示（报告将其标为警告）。
- 涉及动态依赖的结论，注明"运行时加载"属性并引用 specifier 说明来源。
