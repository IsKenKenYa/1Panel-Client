# 测试用例 1：沉浸式方案咨询与选型

## 场景描述
开发者首次接触鸿蒙沉浸式能力，希望了解有几种方案以及各自适用什么场景，需要 AI 代理给出方案对比和选型建议。

## 前置条件
- 应用基于 Stage 模型 + ArkTS（`@ohos.window`）
- 开发者了解状态栏、导航条、安全区的基本概念（或 AI 代理需先解释）

## 执行步骤
1. AI 代理识别"沉浸式方案""沉浸式选型"等关键词，触发本技能（场景 IMM-01）
2. AI 代理列出 3 种方案：组件页面沉浸（`.ignoreLayoutSafeArea()`）、安全区域拓展（`.expandSafeArea()`）、窗口沉浸式显示（`setWindowLayoutFullScreen`）
3. AI 代理对比各方案层级（组件级 vs 窗口级）、特点、适用场景
4. AI 代理说明选型关键判断：背景延伸 vs 内容延伸、单页 vs 全局、是否需隐藏系统栏
5. AI 代理给出决策树或选型建议表

## 预期结果
- 准确列出 3 种方案及其核心 API/属性
- 明确方案 A 和 C 内容延伸需手动避让，方案 B 内容在安全区无需避让
- 明确组件级方案需每页单独配置，窗口级方案全局生效
- 未虚构不存在的 API 或属性

## 验证方法
- 检查输出是否包含 3 种方案的核心 API：ignoreLayoutSafeArea、expandSafeArea、setWindowLayoutFullScreen
- 检查是否提到组件级需每页配置、窗口级全局生效
- 检查是否给出选型决策树或建议表

## 备注
这是本技能最高频的使用场景。若开发者已明确需求（如"只想背景延伸"），应直接引导至对应方案的实现细节，而非泛泛列举全部方案。
