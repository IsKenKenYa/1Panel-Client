# 测试用例 2：视频播放器悬停布局（折痕避让几何 + 固定操作坞）

## 场景描述
视频播放页要在悬停态做"上半屏播放、下半屏控制"的分区布局，要求内容避开折痕区域、操作区固定不上下拖动、元素与底部保持安全距离。

## 前置条件
- 已完成悬停态监听接入（测试用例 1）
- 页面已实现常规态布局（视频 + 底部控制）
- 沉浸式铺满：`expandSafeArea` 铺满 display，系统栏透明

## 执行步骤
1. AI 代理识别任务落点为布局设计（场景 HVS-03），先读布局模式参考
2. AI 代理给出三段式几何公式：
   - 视频高度 = `creaseTop`（封顶折痕区域上沿，内容严格不进折痕区域）
   - 避让带 = `max(creaseHeight / 2 + 16, 16)`vp（带内纯占位，不放交互/文字）
   - 操作区 = `winHeight −` 前两项
3. AI 代理给出折痕区域获取优先级：实时折痕（API 20+）→ 静态折痕（API 10+）→ 屏幕中线兜底，px 除以 densityPixels 转 vp
4. AI 代理把下半屏实现为固定操作坞：控制元素一次全部呈现（压缩冗余行），仅横向滚动；底部 padding 叠加导航条高度
5. AI 代理说明状态徽标/HUD 放内容区左上角（position 定位 + 状态栏高度避让），不占操作坞垂直空间

## 预期结果
- 视频不压折痕区域、避让带量化为公式而非"留白一整段折痕"
- 操作坞固定不可上下拖动，内容预算不溢出
- 底部安全距离 = 不溢出 + padding 叠加 `TYPE_NAVIGATION_INDICATOR` 实测高度
- 常规态保留 Scroll 兜底，进出悬停过渡动画对称

## 验证方法
- 检查输出是否包含 `creaseTop`、避让带公式、`densityPixels`（除法）
- 检查是否说明"固定高度 Column 子项溢出会穿过底部 padding"的坑
- 真机：半折叠后视频停在折痕上方、黑带约折痕半高 + 16vp、操作区固定、底部留白

## 备注
折痕避让几何为真机三轮打磨定稿：整段折痕区域留白（过大）与内容延伸至折痕中心（压折痕）均被否决。
