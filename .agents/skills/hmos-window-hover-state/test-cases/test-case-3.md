# 测试用例 3：相机悬停拍摄（渲染节点不重建）

## 场景描述
相机页做悬停拍摄：上半屏取景器、下半屏快门与模式切换，进入悬停时预览不能黑屏闪断。

## 前置条件
- 已完成悬停态监听接入（测试用例 1）
- 页面用 XComponent/Surface 承载取景器
- 已有常规态取景布局

## 执行步骤
1. AI 代理识别任务落点为相机场景布局（场景 HVS-03）
2. AI 代理把 XComponent 排除在悬停 if/else 分支之外：同一渲染节点，仅高度/权重等布局参数随状态变化
3. AI 代理按折痕避让几何给取景器高度（封顶折痕区域上沿），快门/模式切换落在折痕下方的固定操作坞
4. AI 代理对下半屏主按钮做人机工学加强（近水平视角：按钮加大、点击区外扩、字号间距上调）
5. AI 代理进入悬停时提示"设备已放稳，触控或定时拍摄"，可配合 `setWindowKeepScreenOn` 保持亮屏

## 预期结果
- 取景器不销毁重建（Surface 不闪黑），仅布局参数变化
- 交互元素全部避开折痕区域，快门在下半屏明显加大
- 悬停进出过渡对称，退出后常规取景布局恢复

## 验证方法
- 检查方案中 XComponent 是否始终在同一组件树位置（不在 if/else 两侧分别声明）
- 真机：半折叠进入悬停，预览连续无黑帧，快门可单指盲操作
