---

### 测试用例：FUNC-001

**skill**：harmonyos-memory-optimization-solution  
**类型**：functional（功能验证）

#### 输入

请描述 harmonyos-memory-optimization-solution 的完整内存优化工作流，从前置检查到构建验证，每个步骤的职责是什么？步骤之间如何通过场景注册表衔接？

#### 预期输出

**验证标准**：

- 应列出步骤 0-5 的完整流程（前置检查→定位场景→读取参考文档给出方案→逐一确认优化点→执行优化→构建验证）
- 应说明步骤 0.1 源码路径为硬性门禁，未提供时立即向用户询问
- 应说明步骤 0.2 故障根因为可选项，未提供不阻塞流程（按方式 A 全量扫描）
- 应说明场景注册表三个字段的衔接方式：applies_when 供步骤 1 定位比对、resource_refs 供步骤 2 读取参考文档、verification_point 供步骤 5 验证

**应包含**：前置检查, 场景注册表, applies_when, resource_refs, verification_point
