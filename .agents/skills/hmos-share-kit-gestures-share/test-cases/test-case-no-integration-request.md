# 用例：未要求接入，不改码

## 目标

用户提到隔空传送，但未要求接入 / 集成 / 补齐时，只答疑或评估，不改工程。

## 前置

- 无强制改码意图；主、备提示词各跑一遍

## 步骤

1. 用 [test-prompts.md](test-prompts.md) 场景 6 **主提示词**跑一遍
2. 用场景 6 **备用提示词**再跑一遍
3. 两次均对照下列通过标准

## 本场景重点标准

不进入改码交付链；验「未要求接入则不改码」边界。

## 通过标准

主提示词与备用提示词**均需满足**：

- [ ] 可简要说明与系统分享的差异、适合分享文件还是链接，或评估是否适合 / 大概改哪些地方
- [ ] **未**修改工程代码
- [ ] **未**注入管理类、业务类，**未**注册 `gesturesShare` 监听
- [ ] 未把对话当成接入任务执行 `test-cases` 内其他接入场景的改码步骤
