# 用例：未指定类型 / 挂载页

## 目标

用户只说「接入隔空传送」、未指定类型与页面时，先定类型，未答清不修改代码。

## 前置

- `targetSdkVersion` ≥ `6.0.0(20)`（或先过核验）
- 提示词不提供页面；工程也无明显可分享页

## 步骤

1. 用 [test-prompts.md](test-prompts.md) 场景 5 触发
2. 观察首轮提问范围与是否改码

## 本场景重点标准

见 [acceptance-checklist.md](acceptance-checklist.md)：S1, S3

## 通过标准

- [ ] 未说明类型时，本轮**只先问**分享类型（文件 / 链接 / 两者）（S3）
- [ ] 本轮提问不附带文件 uri、App Linking 域名等另一类型细节（S3）
- [ ] 类型确定后再问对应必问项与挂载页 / 落盘目录
- [ ] 未答清不修改代码、不注入实现（S1, S3）
