# SDK 版本号写法（API 26 起变更）

官方从 **API 26.0.0** 起调整开发套件版本号：统一用语义化版本 **X.Y.Z**，不再使用 `HarmonyOS版本(API)` 括号写法。  
完整说明见鸿蒙开发者官网-版本号格式调整

改 `build-profile.json5` 前必须打开 [assets/sdk-profile-snippet.json5](../assets/sdk-profile-snippet.json5)，按档位合并字段。**禁止**把该文件整份拷进宿主工程。

## 两套写法

| 档位 | 写入 `compatibleSdkVersion` / `targetSdkVersion` | 格式 |
|------|--------------------------------------------------|------|
| 仅链接 API 20+ | `"6.0.0(20)"` | 旧：`主.次.修订(API)` |
| 含文件不要精准 API 22+ | `"6.0.2(22)"` | 旧：同上 |
| 含文件要精准 API 26+ | `"26.0.0"` | **新：SemVer `X.Y.Z`，无括号** |

禁止把 26+ 写成 `"7.0.0(26)"`、`"6.0.0(26)"`、数字 `26`、字符串 `"26"`。

若宿主已是 `"26.0.1"` / `"26.1.0"` 等 **26.x.y** 且已满足目标，不要降回 `"26.0.0"`。

## 读取当前工程（比较用）

从 `app.products[].compatibleSdkVersion` 与 `targetSdkVersion` 取值后，换算成可比较的 API 主版本：

- 旧写法 `"A.B.C(N)"`（有括号）→ API = **N**（如 `"6.0.2(22)"` → 22）
- 新写法 `"X.Y.Z"` 且 **X ≥ 26**、无括号 → API = **X**（如 `"26.0.0"` → 26，`"27.0.0"` → 27）
- 纯数字 `20`（少见，偏 OpenHarmony）→ API = 该数字

比较规则：当前 API ≥ 目标 API 则不改 SDK。  
目标 20 / 22 / 26 分别对应上表写入串。升 26 时 **compatible 与 target 都写成新格式**（本 Skill 精准档要求最低即 26）。

## 代码侧

`deviceInfo.apiAvailable('26.0.0')` 必须 **字符串字面量** `'26.0.0'`，与新版本号一致。禁止 `'26'`、变量、或 `'6.0.0(26)'`。
