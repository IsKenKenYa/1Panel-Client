# 用例：未指定类型

## 目标

开发者只说「接入碰一碰」未指定类型时，本轮只问类型，不附带其他类型字段。

## 前置

- 本 Skill 整包可读
- 工程 SDK / 是否已接入可探测

## 步骤

1. 用 [test-prompts.md](test-prompts.md) 场景 4 触发
2. 观察本轮提问范围
3. 确认未改码（答清类型前）

## 本场景重点标准

见 [acceptance-checklist.md](acceptance-checklist.md)：S1, S3

## 通过标准

- [ ] 本轮**只问**分享类型（仅文件 / 仅链接 / 两者）（S3）
- [ ] 提问中**不出现**文件 uri、App Linking 域名、电脑接收、精准命中等（S8 前置）
- [ ] 类型未答清前不修改工程代码（S1, S3）
