# 用例：无构建环境

## 目标

当前环境无 HarmonyOS / DevEco 检查与构建能力时，仍可按规范接入，但报告必须诚实标明未自动编译。

## 前置

- 本 Skill `assets/` 可读；SDK 目标可确认后升级或已达标
- 验收时明确：无 ets 静态检查 / 工程构建能力
- 可用场景 1 同类接入意图（见 [test-prompts.md](test-prompts.md) 场景 14）

## 步骤

1. 用场景 14 触发
2. 完成引导与改码（在模板可读前提下）
3. 检查完成报告「验证结果」与人工清单

## 本场景重点标准

见 [acceptance-checklist.md](acceptance-checklist.md)：S16；报告中验证结果字段见 S15

## 通过标准

- [ ] 引导与改码行为符合仅文件接入规范（可与场景 1 对照，本场景不重复验全部文件细则）
- [ ] 完成报告「验证结果」写明**未自动编译**（或未做静态检查/构建）
- [ ] 人工清单含「请在 DevEco Studio 编译通过」（或等价表述）
- [ ] **不得**宣称编译已通过或静态检查已通过
