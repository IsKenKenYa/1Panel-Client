# 用例：非 git 环境回滚 + 用户中途放弃

## 目标

工程不在 git 版控下时，用户中途放弃，agent 输出已改文件清单 + 每处改动摘要供人工还原。

## 前置

- 工程**不在** git 版控下（或 .git 目录被移除 / git 不可用）
- 本 Skill `assets/file/` 可读
- 用户提出接入请求，agent 走到变更写入阶段后用户表示放弃（见 [test-prompts.md](test-prompts.md) 场景 16）

## 步骤

1. 用场景 16 触发
2. 确认阶段 0 记录了"非 git"结论与关键文件清单
3. 确认变更预览后 agent 开始写文件
4. 用户中途插入"算了，不要改了"
5. 观察回滚行为

## 本场景重点标准

见 [acceptance-checklist.md](acceptance-checklist.md)：S22, S23

## 通过标准

- [ ] 阶段 0 记录了工程不在 git 版控下（S22）
- [ ] 阶段 0 列出了即将涉及的关键文件清单（供回滚还原）（S22）
- [ ] 用户放弃后，**未**执行 `git checkout`（因为非 git）（S23）
- [ ] 输出本次会话已改文件清单 + 每处改动摘要，供人工还原（S23）
- [ ] 已拷入的资产文件（Manager/Provider/KnockRectUtil）若属于本次新增 → 在清单中列出
- [ ] 回滚后输出回滚原因（用户放弃）+ 待还原文件清单 + 人工下一步建议（S23）
