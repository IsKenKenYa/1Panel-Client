### 状态定义

- `planned`：范围已确认，尚未开始实现。
- `in_progress`：正在实现，未达到批次验收。
- `blocked`：因契约、环境或依赖无法推进，必须写明解除条件。
- `verified`：交付与门禁均已记录，后续只允许通过新批次扩展。
- `deferred`：明确不在当前批次，必须写明重新评估条件。

## 统一目录模板

第一阶段所有新模块默认使用下列目录模板：

```text
lib/data/repositories/<module>_repository.dart
lib/features/<module>/
  pages/
  providers/
  services/
  widgets/
```

### Provider 拆分规则

默认拆成：

- `*_provider.dart`
  列表/总览状态
- `*_detail_provider.dart`
  详情页状态
- `*_form_provider.dart`
  创建/编辑表单状态

若模块没有表单或详情，可酌情减少，但不得将列表、详情、表单、日志、批量动作全塞进一个 Provider。

### Repository 与 Service 边界

- `Repository`
  负责对接 API client、请求体组装、响应体映射、错误转换
- `Service`
  负责跨 repository 编排、动作流程、缓存复用、轮询/同步策略
- `Provider`
  只负责 UI 可观察状态与用户动作分发
